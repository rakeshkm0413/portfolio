# 🧭 COMPLETE SETUP — START TO END

### ✅ Step 1 — Create the ZIP manually (2 minutes)

1. **Desktop** → Right-click → **New Folder** → name it **`rakesh-portfolio`**
2. Inside it → right-click → **New Folder** → name it **`assets`**
3. Open **Notepad** → paste `index.html` → **Save As** → 
   - File name: `index.html`
   - Save as type: **All Files**
   - Location: `rakesh-portfolio`
4. Repeat for `style.css`, `script.js`, `README.md`
5. Drop into `assets/`:
   - `rakesh.jpg` (your photo)
   - `Rakesh_Kumar_Mistri_Resume.pdf` (your resume)
6. **Right-click `rakesh-portfolio` folder** → **Send to** → **Compressed (zipped) folder**
7. You now have **`rakesh-portfolio.zip`** ✅

### ✅ Step 2 — Test Locally
Open `rakesh-portfolio/index.html` → test:
- Theme toggle (🌙 ↔ ☀️)
- All 6 project links
- Contact form → submit test → check Gmail
